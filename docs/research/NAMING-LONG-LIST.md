## Strongest recommendation

**Carrymark** is the best first candidate. It conveys **user-owned continuity** rather than generic AI memory, has a physical/portable feel, and leaves room for the product to evolve beyond handoff links. The main issue is the spoken/search confusion with **Caremark**, so early testing should include hearing the name aloud and observing whether people type it correctly.

**Workcarry** is the clearest consumer utility name. It sacrifices some distinctiveness, but users immediately understand the promise.

**Stateparcel** is the strongest name if the product wants to foreground its differentiator: a structured, canonical object that travels intact. It is more technical and has a mild GIS/real-estate association.

## Explicit rejects

I would reject these as primary names:

- **Agent USB** — memorable internal metaphor, but “USB” implies hardware, removable storage, or malware/security concerns. Also, `.usb` is not a public delegated TLD in the IANA root-zone list; it should remain a product metaphor, not a domain assumption.[6]
- **Relay Capsules** — already used by a Devpost project for portable coding-agent task capsules.[5]
- **Relay** — heavily occupied across messaging, infrastructure, payments, and agent handoff concepts; it describes transfer, not user ownership.
- **Capsule** — already strongly associated with the Devpost project and broadly crowded in software, healthcare, and logistics.
- **Handoff** — category terminology, not a distinctive consumer brand; LangChain and OpenAI documentation already use it as a standard architecture term.[3]
- **Context Pack** — directly occupied by an agent-handoff MCP tool.[4]
- **Memory / Portable Memory** — increasingly crowded and semantically narrows the product to storage or personalization; Walrus Memory already claims the portable-agent-memory position.[2]
- **Passport** — intuitive but highly crowded across identity, travel, developer access, and AI products.
- **Briefcase** — excellent metaphor, but crowded as a productivity/software/productivity brand and potentially too enterprise-oriented.
- **Pocket** — appealing consumer tone, but heavily occupied by AI assistants, note-taking, and capture products; **Pocketstate** is safer than using Pocket alone.
- **Continuum / Continue / Continuance** — continuity is relevant, but these names are crowded, abstract, and difficult to own. “Continue” is already associated with developer tooling.
- **Workpass / Statecard / Carrycard** — understandable but collision-prone: WorkPass is an existing business-network product, while card/pass language suggests credentials, payments, or employee access.
- **Taskcase / Workkit / Workbox / Workfolio** — familiar compounds but already saturated by task management, productivity, developer, and workplace products.

No domain availability is asserted here. These are naming candidates only; any finalist should receive separate trademark screening, exact social/app-store checks, and authoritative RDAP checks for the intended TLD.
